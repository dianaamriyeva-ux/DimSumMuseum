# DimSumMuseum — Future Fortune Museum

A satirical digital museum set in 2126. Corporations have commercialized fortune
symbols from Indian, Chinese, Greek and Indigenous cultures, and the future
curators misread what they meant.

Open `index.html` in a browser; there is no build step.

- `js/exhibits.js` holds every exhibit's text, labels, visitor comments and drawings. Edit the text here.
- `js/main.js` builds the page and handles comments, likes and theory submissions.
- `css/style.css` styles the timber pavilion look.

Hidden comments ("View anyway") hold the real meaning of each object.
